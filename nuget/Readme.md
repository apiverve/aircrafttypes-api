Aircraft Types API
============

Aircraft Types returns the physical and operational characteristics of an aircraft type from its ICAO designator, such as B738 or A320, or by searching manufacturer and model. Each type comes with wingspan, length, tail height, maximum takeoff and landing weight, approach speed and category, airplane design group, ICAO wake turbulence category and FAA weight class, with metric conversions. Paid plans add airport planning geometry, RECAT wake categories and US registration and traffic counts.


[![NuGet version](https://img.shields.io/nuget/v/APIVerve.API.AircraftTypes.svg)](https://www.nuget.org/packages/APIVerve.API.AircraftTypes)

This is a .NET wrapper for the [Aircraft Types API](https://apiverve.com/marketplace/aircrafttypes?utm_source=nuget&utm_medium=referral&utm_content=readme)

Using the Package Manager:

Using the Package Manager Console:

## Quick Start

Here's a simple example to get you started quickly:

```csharp
using System;
using APIVerve.API.AircraftTypes;

class Program
{
    static async Task Main(string[] args)
    {
        // Initialize the API client
        var apiClient = new AircraftTypesAPIClient("[YOUR_API_KEY]");

        var queryOptions = new AircraftTypesQueryOptions {
            Icao = "B738",
            Manufacturer = "Airbus",
            Model = "737",
            EngineType = "jet",
            WakeCategory = "heavy",
            Engines = 2,
            Limit = 10
        };

        // Make the API call
        try
        {
            var response = await apiClient.ExecuteAsync(queryOptions);

            if (response.Error != null)
            {
                Console.WriteLine($"API Error: {response.Error}");
            }
            else
            {
                Console.WriteLine("Success!");
                // Access response data using the strongly-typed ResponseObj properties
                Console.WriteLine(Newtonsoft.Json.JsonConvert.SerializeObject(response, Newtonsoft.Json.Formatting.Indented));
            }
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Exception: {ex.Message}");
        }
    }
}
```

## Error Handling

The API client provides comprehensive error handling. Here are some examples:

### Handling API Errors

```csharp
using System;

            Limit = 10
        };

        try
        {
            var response = await apiClient.ExecuteAsync(queryOptions);

            // Check for API-level errors
            if (response.Error != null)
            {
                Console.WriteLine($"API Error: {response.Error}");
                Console.WriteLine($"Status: {response.Status}");
                return;
            }

            // Success - use the data
            Console.WriteLine("Request successful!");
            Console.WriteLine(Newtonsoft.Json.JsonConvert.SerializeObject(response, Newtonsoft.Json.Formatting.Indented));

            // Invalid API key or parameters
            Console.WriteLine($"Invalid argument: {ex.Message}");
        }
        catch (System.Net.Http.HttpRequestException ex)
        {
            // Network or HTTP errors
            Console.WriteLine($"Network error: {ex.Message}");
        }
        catch (Exception ex)
        {
            // Other errors
            Console.WriteLine($"Unexpected error: {ex.Message}");
        }
    }
}
```

## Advanced Features

### Custom Headers

Add custom headers to your requests:

```csharp
var apiClient = new AircraftTypesAPIClient("[YOUR_API_KEY]");

// Add custom headers
apiClient.AddCustomHeader("X-Custom-Header", "custom-value");
apiClient.AddCustomHeader("X-Request-ID", Guid.NewGuid().ToString());

var queryOptions = new AircraftTypesQueryOptions {
    Icao = "B738",
    Manufacturer = "Airbus",
    Model = "737",
    EngineType = "jet",
    WakeCategory = "heavy",
    Engines = 2,
    Limit = 10
};

var response = await apiClient.ExecuteAsync(queryOptions);

// Remove a header
apiClient.RemoveCustomHeader("X-Custom-Header");

// Clear all custom headers
apiClient.ClearCustomHeaders();
```

### Retry Configuration

Customize retry behavior for failed requests:

```csharp
var apiClient = new AircraftTypesAPIClient("[YOUR_API_KEY]");

// Set retry options
apiClient.SetMaxRetries(3);           // Retry up to 3 times (default: 0, max: 3)
apiClient.SetRetryDelay(1500);        // Wait 1.5 seconds between retries (default: 1000ms)

    Manufacturer = "Airbus",
    Model = "737",
    EngineType = "jet",
    WakeCategory = "heavy",
    Engines = 2,
    Limit = 10
};

var response = await apiClient.ExecuteAsync(queryOptions);
```

### Dispose Pattern

The API client implements `IDisposable` for proper resource cleanup:

```csharp
var queryOptions = new AircraftTypesQueryOptions {
    Icao = "B738",
    Manufacturer = "Airbus",
    Model = "737",
    EngineType = "jet",
    WakeCategory = "heavy",
    Engines = 2,
    Limit = 10
};

using (var apiClient = new AircraftTypesAPIClient("[YOUR_API_KEY]"))
{
    var response = await apiClient.ExecuteAsync(queryOptions);
    Console.WriteLine(Newtonsoft.Json.JsonConvert.SerializeObject(response, Newtonsoft.Json.Formatting.Indented));
}
// HttpClient is automatically disposed here
```
